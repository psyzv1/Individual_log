## Training phase: Fitbit dashboard (TAG task)

In the training phase, our team built a Streamlit dashboard using Fitbit data from 33 users. My main contributions were:
- **Data exploration** of the sleep, weight and minute-level steps files, including data quality issues such as duplicates, sparse weight data and mismatched date ranges
- **Requirements** written in EARS, including a privacy requirement to keep weight and BMI off group views
- **Streaks and friends leaderboard** features, with unit tests
- **Code review**, finding two bugs in shared code
- **The dashboard demo** in our retrospective video
- **A peer review** of other teams' videos (in Week 8 of the log)

Team repository: `DATA2007-Fitbit-Dashboard-Group` (private)
